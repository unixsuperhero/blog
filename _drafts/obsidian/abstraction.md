abstractions or generalization

there is a difference between pdf generation and document generation
if you are building an app, it probably makes more sense to call the system document generation because  it's likely that all documents share the same high level operations.  and the specifics, which is where the complexity is... can be pushed down.

taking a step back, seeing the patterns that things share, is how you build systems instead of one off scripts.
